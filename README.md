# Rust-intensive

A hardcore, project-driven engineering track designed to master Rust for high-throughput, low-latency fintech applications. This repository contains 20 production-grade mini and midi systems built completely from scratch, shifting mental paradigms from managed memory (Java/C#) to explicit ownership, lifetimes, and low-level resource management.

**M0-P1:** `hello-cli-formatter` (`std::io::stdin`, String parsing, Error handling with `Result`/`match`)
